# ルドット / LUDOT

制作チームの作品と投稿作品を集めた、無料ブラウザゲームのコレクション。

- 1ゲーム＝1フォルダ（`games/`配下）
- 新しいゲームは `games.js` に1ブロック追加すると一覧に表示されます

## 検索向けページの更新

ゲーム追加・説明文変更後は `node scripts/build-seo.mjs` を実行し、トップの静的リンク、各ゲームの説明・正規URL、サイトマップを一緒に更新してください。既存URLとゲームの保存キーは継続しています。お気に入り・最近遊んだゲームは利用者のブラウザ内に保存します。

## 遊び方一覧の更新

公開作品を追加・変更したら `node scripts/build-guide.mjs --refresh` を実行し、公開一覧を再取得してください。取得失敗時は古い一覧を消さず、公開を保留します。`node scripts/build-seo.mjs` は保存済みの公開一覧と本体作品から説明を再生成します。公開前に `node scripts/check-site.mjs` と `node scripts/check-ad-placement.mjs` でリンク・説明・広告配置を検査してください。実際のゲーム操作や素材の権利の確認は別途必要です。

## 記事と関連記事の更新

`node scripts/build-blog-index.mjs` は各記事の説明・見出し・確認日から一覧と構造化データを同期します。`build-seo.mjs` からも呼ばれます。新規記事は正しい公開日・更新日・画像をBlogPostingに入れてください。ゲームと記事の対応は `scripts/article-map.mjs` が正本です。ガイドの静的リンクとゲームの関連記事リンクへ反映し、ゲームとの対応も検証します。記事を加えたらサイトマップも再生成し、画面・リンク・広告配置を確認してください。自動検査は素材の許諾や実プレイ確認の代わりにはなりません。

## 2026-11-16 検索とおすすめ対象

- `assets/ludot-discovery.js` が対象・ジャンル・検索別名・条件復元を担当。`index.html` はこの共通判定を使う。
- 「大人向け」は内容を確認した `ADULT_IDS` の作品だけ。年齢の数字や「全年齢」、子ども向けではないという理由で自動追加しない。新作は全作品一覧には載り、大人向けは内容確認後に明示追加する。
- 「子ども向け」も内容で分類。子どもの年齢はその中で絞り込む。おすすめ対象と登録済みの遊びやすさ目安を混同しない。
- 英語名を含む新作には必要に応じて検索用別名を追加する。既知の名前に完全一致する検索では、説明の偶然の部分一致を混ぜない。
- 絞り込み中は新着・推薦・個人棚を隠す。お気に入りや履歴の保存キー・全カタログは維持する。
- 公開ソースはGitHubの最新を取得する。過去の作業コピーで上書きしない。
